# DSH 媒体库

将现有 DSH 项目设为媒体库，在项目目录内浏览、播放媒体并编辑标签。

## 使用

1. 在左侧项目上右键，选择「设为媒体库」。插件直接使用这个项目的已有目录，不要求填写第二份路径，也不需要为设置重启 DSH。
2. 选中该项目的任意会话，媒体库在聊天旁边打开。视频网格递归读取项目中的视频；点选视频播放。实际解码能力由浏览器决定，不做转码。
3. 在「标签分类」中创建分类和标签，在视频预览中选择多个标签并保存，也可以直接输入标签。未打标签的视频显示为「未分类」。Agent 可浏览媒体目录并追加标签。
4. 已设置的项目右键提供「打开媒体库」和「取消媒体库」。取消只移除媒体库登记，原文件、标签和项目会话保留。

没有项目时，先使用 DSH 原有的「添加工作区」。插件详情页也有「打开媒体库」入口。切回聊天不改变原会话及模型。

## 数据与范围

项目目录、标题和身份由官方 Workspace 服务持有；插件保存 Workspace 身份集合、标签分类与媒体标签，位于实际 DSH Home 的 `state/media-library/`。不复制、移动、删除或改写原媒体，不自动标记用户项目。视频网格递归读取目录并分页请求，目录变化后要求刷新。登记与标签是本机业务数据，不是跨机器的便携配置；不要将它们加入共享环境库。

文件接口要求 DSH Connection 认证的 owner；非 owner Peer 被拒绝。路径必须位于已登记的项目中，拒绝绝对路径、父目录遍历、隐藏路径、Windows ADS/设备名和子级符号链接/联接（包括指向项目内的链接）。图片允许常见光栅格式，不提供 HTML/SVG。Range 请求只支持一个字节区间。Windows 的路径检查不是对并发恶意换链的原子沙箱，仅用于可信的用户项目；不要将攻击者可写的目录设为媒体库。

当前交付仅验证维护 fork 声明的 Windows 源码 Web 环境。保留原 OpenList 读取模块及其测试；本版页面只接本地项目，不读取网盘凭据或连接云服务。

## 安装与验证

通过 DSH 同步器或官方 CLI 安装本仓库的固定 Git 提交。插件以已检查的 JavaScript 源文件运行，没有安装生命周期或额外构建依赖；不要以本地 link 或复制覆盖安装目录代替安装。第一次加载插件是否需要重启，按宿主官方 lifecycle 的实际结果处理；后续设置项目与标签不需要重启。

`npm test` 验证真实临时文件、目录边界、持久化、认证、Range 与失败路径。`npm run build` 检查所有运行 JavaScript 的语法。`npm run test:client -- <当前 DSH 源码目录>` 使用该宿主的 React 执行生产组件和模拟 API/控件，不等同于实际页面验收。发布还需独立 DSH Home/端口和真实页面验收，不向测试环境复制正式凭据或会话。
